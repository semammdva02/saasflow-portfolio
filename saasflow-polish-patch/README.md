# SaaSFlow — AI Workflow Automation

A portfolio-grade SaaS landing page built to demonstrate modern frontend engineering and product UI skills.

## Live demo

https://saasflow-portfolio.vercel.app/

## Stack

- Next.js 16 + App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Responsive UI
- Small client components for interactive islands

## What this project demonstrates

- Premium SaaS landing-page UI
- Responsive navigation with mobile menu
- Product dashboard visualization
- Workflow builder presentation
- Accessible interactive pricing toggle
- Native FAQ disclosure
- Semantic page landmarks and keyboard focus states
- SEO metadata, canonical URL, robots and sitemap
- Open Graph social preview image
- Clean separation of server and client components

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Validate

```bash
npm run build
npm run lint
```
