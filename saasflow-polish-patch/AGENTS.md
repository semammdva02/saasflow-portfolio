# SaaSFlow coding guide

## Project
SaaSFlow is a portfolio-grade SaaS landing page built with Next.js, TypeScript and Tailwind CSS.

## Principles
- Keep the UI responsive from mobile to large desktop.
- Prefer semantic HTML and accessible controls.
- Keep components small and reusable when the page grows.
- Do not add dependencies unless they solve a real problem.
- Preserve the visual system: deep navy background, cyan/blue/violet accents, soft borders and rounded cards.

## Validation
Run `npm run build` and `npm run lint` before shipping changes.
