# SaaSFlow — AI Workflow Automation

A portfolio-grade SaaS landing page built to demonstrate modern frontend skills.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Responsive UI
- Client-side interactions

## Included

- Responsive navigation with mobile menu
- Premium hero section
- Product dashboard preview
- Features
- Workflow automation showcase
- Integrations section
- Pricing toggle
- Testimonials
- FAQ accordion
- Final CTA and footer

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm run start
```

## Portfolio purpose

This project is designed to demonstrate frontend implementation for SaaS landing pages, responsive product interfaces, dashboard UI and client-focused web experiences.
